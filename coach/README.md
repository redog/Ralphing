# Coach workspace

This directory is persistent state for developing Ralphing into a practical AI
coaching program. It is intentionally separate from learner-facing material.

The `ralph-coach` skill reads `COACHING_PLAN.md`, chooses one incomplete module,
builds or improves the learner material, exercise, facilitator notes, and
evaluation method, then updates the plan with evidence and unresolved questions.

## Working rhythm

1. Select one incomplete coaching outcome.
2. Build the smallest teachable module.
3. Rehearse it with synthetic inputs.
4. Run it with a person or a five-platform comparison.
5. Record observations using `templates/coaching-retrospective.md`.
6. Revise the material and update the plan.

Progress comes from observed learning, not the volume of generated pages.
