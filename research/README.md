# Research archive

This area separates source collection from original teaching and engineering
material.

- `sources.md` is the annotated research index.
- `sources.csv` is the machine-readable source inventory.
- `archive/web-extracts/` contains captured third-party pages or repository
  extracts used during early research.
- `archive/original-reverse-engineer-ralph-prompt.md` preserves an early project
  prompt that was later developed into the Hplar skill.

Archived extracts are not learner-facing documentation and are not covered by
the repository license merely because they are stored here. Prefer links to
primary sources and original synthesis in maintained documentation. See the
root `NOTICE.md`.
